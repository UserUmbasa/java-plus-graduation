API Комментариев для Events With Me

🗂️  Модуль комментариев позволяет пользователям оставлять комментарии к событиям,    редактировать и удалять их.  
Администраторы имеют расширенные права управления комментариями.

## Уровни доступа:

🔓  Public  -  просмотр комментариев к событиям

🔐  Private  -  управление своими комментариями  (требуется аутентификация)

⚡  Admin  -  полное управление всеми комментариями

## 🗄️  Схема БД  Модель

Comment  sql  CREATE TABLE IF NOT EXISTS comments   
(  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,  
event_id BIGINT NOT NULL,  
user_id BIGINT NOT NULL,  
text TEXT NOT NULL,  
created_at TIMESTAMP WITHOUT TIME ZONE DEFAULT CURRENT_TIMESTAMP,  
updated_at TIMESTAMP WITHOUT TIME ZONE DEFAULT CURRENT_TIMESTAMP,    
status VARCHAR(20)  DEFAULT  'PUBLISHED'  NOT NULL  );

## Статусы комментариев
PUBLISHED Опубликованный комментарий  
EDITED Отредактированный комментарий  
DELETED Удаленный комментарий  (soft delete)



## 🔄  Жизненный цикл комментария

Создание  →  PUBLISHED

Редактирование  →  EDITED

Удаление  →  DELETED  (soft delete)

## 📊  Правила видимости

Public endpoints: показывают только PUBLISHED и EDITED  
Admin endpoints: показывают все статусы, включая DELETED

## Права доступа:

Пользователь  →  только свои комментарии

Администратор  →  все комментарии

## Валидация:

Текст:  1-2000 символов

Только к опубликованным событиям

Нельзя редактировать удаленные комментарии

## 📡  API Endpoints  🔓

**Public Endpoints**

GET  /events/{eventId}/comments Получить комментарии события  
GET  /events/{eventId}/comments/{commentId}  Получить конкретный комментарий

**Private Endpoints**



POST  /users/{userId}/events/{eventId}/comments Создать комментарий  
PATCH  /users/{userId}/comments/{commentId} Редактировать комментарий  
DELETE  /users/{userId}/comments/{commentId} Удалить комментарий  
GET  /users/{userId}/comments Комментарии пользователя

**Admin Endpoints**

  
GET  /admin/comments Все комментарии с фильтрацией (от новых к старым)  
DELETE  /admin/comments/{commentId}  Удалить любой комментарий

## 🗃️  Примеры использования

📝  **Создание комментария**  
http  POST  /users/1/events/2/comments  Content-Type:  application/json
{  "text": "Отличное событие!  Обязательно приду."  }  

👀  Просмотр комментариев  
http  GET  /events/2/comments?from=0&size=10  

✏️  Редактирование комментария  
http  PATCH  /users/1/comments/5  Content-Type:  application/json
{  "text": "Обновленный текст комментария"  }

🛡️  **Административное удаление**  
http  DELETE  /admin/comments/8

🔍  **Административный поиск**  
http  GET  /admin/comments?events=1,2&users=3&from=0&size=20

⚠️  Обработка ошибок
Формат ответа об ошибке

json  {  
    "message": "Текст ошибки",  "reason":  
    "Причина ошибки",  "status": "HTTP_STATUS",  
    "timestamp": "2024-01-15 12:00:00"  
}


## Код Ситуация

**400** Ошибки валидации  
**403** Недостаточно прав  
**404** Сущность не найдена  
**409** Нарушение бизнес-правил
